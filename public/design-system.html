08 · Accessibility

Baked into the system

  • ✓  Strong text contrast — ink on light surfaces meets WCAG AA.
  • ✓  Never colour alone — every status carries text + icon as well as colour.
  • ✓  Tap targets ≥ 44px across all interactive components.
  • ✓  Focus states are visible (brand ring) on every input.
